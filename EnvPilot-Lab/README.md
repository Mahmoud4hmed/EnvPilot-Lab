# EnvPilot Lab

Start with [START_HERE.md](START_HERE.md).

This is a 14-hour, two-day engineering lab for developers with practical backend or full-stack experience. You investigate and repair a fictional environment-management product, with particular emphasis on API correctness, tenant isolation, PostgreSQL performance, asynchronous reliability, and operational debugging. Additional exercises cover React/TypeScript, Ansible, and applied AI/RAG.

Read the [repository overview](../README.md) for the lab's purpose, audience, and training focus. Use the dashboard to observe product behavior and the [in-app guide](http://localhost:8090/guide) to read the assignments. Implement changes in your editor, run the CLI checks, and record your engineering evidence. The starter contains intentional defects for you to repair.
